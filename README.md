Sobre o Projeto
Este projeto foi desenvolvido como atividade prática da disciplina de Programação Web do Curso de Desenvolvimento de Sistemas.
O objetivo consistiu na criação de uma página Web One Page utilizando HTML5, CSS3 e o framework W3.CSS, aplicando conceitos de estruturação de páginas, responsividade, design visual e organização de conteúdo institucional.
A empresa apresentada é fictícia e foi criada exclusivamente para fins acadêmicos.
Empresa
RC Tech Solutions
Slogan:
"Inovando hoje para transformar o amanhã."
A RC Tech Solutions é uma empresa fictícia especializada em desenvolvimento de software, criação de websites, sistemas web personalizados e soluções digitais para empresas de diversos segmentos.
Objetivos do Projeto
•	Aplicar conceitos de HTML5.
•	Utilizar o framework W3.CSS.
•	Desenvolver uma página responsiva.
•	Utilizar ícones da biblioteca Font Awesome.
•	Organizar conteúdo institucional em formato One Page.
•	Desenvolver uma interface moderna e intuitiva.
•	Aplicar boas práticas de programação web.

Responsividade
O site foi desenvolvido com foco em responsividade, permitindo visualização adequada em:
•	Computadores;
•	Tablets;
•	Smartphones.
O framework W3.CSS foi utilizado para facilitar a adaptação automática dos elementos em diferentes tamanhos de tela.
